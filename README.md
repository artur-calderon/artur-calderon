## 🚀 Sobre mim

Sou desenvolvedor com foco crescente em **DevOps, Cloud e infraestrutura**, apaixonado por transformar aplicações em ambientes confiáveis, automatizados e escaláveis.

Atualmente estou aprofundando meus conhecimentos em:

- 🐳 Docker & Docker Compose
- ☸️ Kubernetes
- 🔄 CI/CD & GitHub Actions
- ☁️ Cloud & AWS
- 🐧 Linux & Networking
- 🌐 Nginx & Traefik
- 🔐 Segurança e boas práticas de infraestrutura
- ⚙️ Backend & APIs
- 🏗️ Arquitetura de sistemas

Meu objetivo é unir **desenvolvimento + infraestrutura + automação** para construir soluções completas.
